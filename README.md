## 4. 七个引用陷阱

1. **3080 是 20GB 改装卡**（公版 10/12G），且走 **OCuLink 不是雷电**
2. 27B 的 **+44%** 是对比"3080 单卡"，不是对比 395 整机
3. 最高预填档与最高解码档是**两个不同工作档**，混用即造假
4. V2 的 prefill 两边输入长度不同（3600 vs 2047），作者原话"不能算倍率"
5. **聚合解码含 TTFT**，不能当纯 decode 吞吐
6. Flash 的 capacity / special_pp2 是两套配比（C6 分别 414.9 / 284.6）
7. v2.x 的 9B 行标注 `public-label-no-internal-allocation`（不含调度开销），与 v1 的 server-second-run 口径不同

**可借鉴的两点**：
1. PD 分离在长输入下确实值：V10（1×6000D + 4×Spark）100K 预填 10,000+，是我们四机的两倍多，代价是端到端解码掉到 214
2. 小卡做 P 卡：3060/3080 单卡预填就能压过整机，配合大内存主机是低成本池化思路

## 附录 A · 复现方法（这些实验怎么搭）

上游仓库不提供完整部署脚本，下面是按它的实验说明 + 我们的实践整理的复现路径。

### A.1 PD 分离通用结构

```
[客户端] ──> [P 节点：小卡跑 Prefill] ──KV──> [D 节点：大内存机跑 Decode] ──> 输出
```

- **P 节点**：RTX 3060 12G / 3080 20G / 4090 48G，跑 llama.cpp 或 SGLang 的 prefill-only
- **D 节点**：AI Max+ 395（128GB 统一内存）/ DGX Spark / M3 512G，跑 decode
- **KV 传输**：KV Cache 通过以太网 / Thunderbolt / OCuLink 从 P 搬到 D

### A.2 SGLang PD 分离示例

```bash
# P 节点（小卡）
python3 -m sglang.launch_server --model-path <model> \
  --tp 1 --port 30000 \
  --disaggregation-mode prefill \
  --disaggregation-transfer-backend mooncake   # 或 nixl

# D 节点（大内存）
python3 -m sglang.launch_server --model-path <model> \
  --tp 1 --port 30001 \
  --disaggregation-mode decode \
  --disaggregation-transfer-backend mooncake \
  --disaggregation-bootstrap-port 8998
```

### A.3 vLLM PD 分离示例

```bash
# P
vllm serve <model> --port 8100 \
  --kv-transfer-config '{"kv_connector":"NixlConnector","kv_role":"kv_producer"}'

# D
vllm serve <model> --port 8200 \
  --kv-transfer-config '{"kv_connector":"NixlConnector","kv_role":"kv_consumer"}'
```

### A.4 小卡做 P 的关键配置

| 项 | 建议 | 原因 |
|---|---|---|
| batch size | 1–4 | 小卡显存小，大 batch 直接 OOM |
| 交接粒度 | 按层 / 按 chunk | 全量 KV 一次性搬运延迟高（9B 的 full-pd 交接 208.57 MiB） |
| 链路 | OCuLink > Thunderbolt > 以太网 | 3080 那份仓库用的是 **OCuLink**，不是雷电 |
| 解码端 | 显存优先 | 解码是 memory-bound，要大带宽大显存 |

### A.5 融合流水线（v2 路线）

9B 那份实验（v2.1 → v2.4）不是 PD 分离，而是**算子级融合**：小卡与大内存机同跑一层，交替计算。收益从 1452（PD）涨到 2129（融合），说明这类组合的收益主要在**算子级融合**而非简单分工。

实现要点：
- 层切分按"热层放小卡、冷层放大内存机"
- 两边流水线重叠（overlap），避免串行等待
- 负载均衡按每层耗时动态分配

### A.6 测数据时必须注意

1. 预填必须做 **nonce 前缀 + cached=0 校验**，否则测的是缓存
2. 并发档位要跑 1/2/4/8，聚合吞吐和单流吞吐分开报
3. 对照组必须是**同模型同量化同提示词**，否则倍数没意义
4. 解码吞吐要说明"含不含 TTFT"
