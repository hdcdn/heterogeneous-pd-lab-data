## 引用陷阱（摘要）

1. 3080 是 **20GB 改装卡**，走 **OCuLink** 不是雷电
2. 27B 的 +44% 是"对比 3080 单卡"，不是对比 395 整机
3. 聚合解码**含 TTFT**，不能当纯 decode 吞吐
4. 对方四机 Spark C8 323.24、预填 4138.75 —— 与我们实测（317.0 / 4875）同量级
